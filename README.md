# 🚀 AstraWatch

A feature-rich space dashboard web application that brings astronomy and telemetry right to your browser.

## ✨ Features
- **NASA APOD Telemetry**: Automatically fetches the Astronomy Picture of the Day from NASA's official API, supporting images, direct videos, and media embeds.
- **Interactive Date Picker**: Navigate through past space imagery dynamically by selecting any date.
- **Live Clock & Date**: Real-time updating local clock and calendar widget.
- **Custom Google Search Bar**: Sleek glassmorphism search input connected directly to Google.
- **Modern UI / UX**: Styled using advanced CSS techniques including custom pseudo-elements, polygon clip-paths, and Google Fonts (Orbitron & Black Ops One).

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES Modules)
- **Bundler**: Vite
- **API**: NASA APOD API
